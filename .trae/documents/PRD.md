## 1. 产品概述

面向播客主和音乐人的创意设计平台，专注于专辑封面与节目卡片的快速制作。提供从模板选择、画布编辑到批量导出的一站式设计体验。

- 核心目标：降低播客主和音乐人无需专业设计技能，几分钟产出高质量视觉素材
- 市场价值：填补音频创作者专属设计工具的空白，提供批量出图效率提升10倍

## 2. 核心功能

### 2.1 功能模块

1. **主编辑器页面**：模板广场、画布编辑区、左侧工具栏、右侧属性面板、顶部操作栏

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主编辑器 | 模板广场 | 预设专辑封面/节目卡片模板、分类浏览、一键套用 |
| 主编辑器 | 画布编辑区 | 方形/竖版尺寸切换、元素拖拽、缩放、旋转、多选 |
| 主编辑器 | 字体面板 | 字体选择、字号、字重、行高、字间距、对齐方式 |
| 主编辑器 | 配色方案 | 预设配色、自定义颜色、品牌色保存、渐变色生成器 |
| 主编辑器 | 图片处理 | 照片上传、智能头像裁切、滤镜效果、阴影描边调整 |
| 主编辑器 | 批量出图 | 批量替换期数标题、多平台裁切预览、高清导出 |
| 主编辑器 | 作品库 | 历史版本、作品保存、分享只读链接、恢复误删元素 |

## 3. 核心流程

用户从模板广场选择模板→进入画布编辑→调整文本/图片/配色→添加二维码/图标→批量设置→导出或保存至作品库

## 4. 用户界面设计

### 4.1 设计风格
- 主色：深墨黑(#0a0a0f) + 霓虹紫(#8b5cf6) + 霓虹粉(#ec4899)
- 辅助色：琥珀黄(#f59e0b) + 青绿(#10b981)
- 按钮：胶囊形按钮，霓虹发光边框，悬停时有柔和动画
- 字体：Space Grotesk 展示字体 + Inter 正文字体
- 布局：三栏布局（左工具-中画布-右属性），暗色玻璃拟态面板
- 图标：Lucide 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 主编辑器 | 模板广场 | 网格卡片布局、悬停放大、选中发光边框 |
| 主编辑器 | 画布编辑区 | 深色画布、网格辅助线、选中框拖拽手柄、旋转控制 |
| 主编辑器 | 字体面板 | 字体预览列表、滑块控制、颜色选择器 |
| 主编辑器 | 配色方案 | 色板卡片、渐变编辑器、品牌色收藏夹 |
| 主编辑器 | 作品库 | 时间轴版本历史、缩略图卡片、分享按钮 |

### 4.3 响应式设计：桌面端优先，1440px+最佳体验，1024px自适应，768px以下折叠面板
